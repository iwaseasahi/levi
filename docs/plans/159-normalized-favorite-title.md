# Issue #159: 終了節省略時のお気に入り名を正規化済み範囲に合わせる

## Issue

- GitHub Issue: #159
- Branch: `codex/issue-159`
- Base SHA: `2b3a49c`

## Outcome

終了節を省略した検索をお気に入りへ保存したとき、表示名と保存された検索範囲が一致する。

## Context

検索条件は `normalizedSearch` が連続する最終節まで補完する一方、お気に入り名は入力値だけを参照している。このため、たとえば 3 章 16 節から終了節を省略すると、検索範囲は 3:16-18 でも表示名は 3:16 になる。

## Constraints

- 明示的に入力した終了節の表示形式を維持する。
- 単一節として正規化された場合は範囲表記へ変えない。
- 保存済みデータや DB スキーマは変更しない。

## Non-goals

- お気に入り機能全体の分割・再設計
- 聖書検索フォーム全体のリファクタリング

## Plan

1. 終了節省略時の保存タイトルと検索範囲を確認するコンポーネントテストを追加する。
2. 正規化済み検索条件から省略された終了節をタイトルへ反映する。
3. E2E で実ブラウザから保存される名称を検証する。
4. 必須チェックと CI を通し、PR を作成してマージする。

## Progress

- 2026-08-23: Issue、作業ブランチ、worktree、writer lease を準備。
- 2026-08-23: 原因を `favoriteTitle` と `normalizedSearch` の参照値の不一致に特定。
- 2026-08-23: 正規化済み終了節をタイトルへ反映し、コンポーネントテストと E2E を追加。
- 2026-08-23: `pnpm check`、E2E、セキュリティチェックが成功。

## Decisions

- 入力値を上書きせず、タイトル生成時だけ正規化済み検索条件を参照する。
- 終了節を明示入力した場合は従来どおり `開始節-終了節` と表示する。

## Risks

- 保存タイトルだけが変わり、検索範囲や投影 URL の既存挙動は変わらないことを回帰テストで確認する。
