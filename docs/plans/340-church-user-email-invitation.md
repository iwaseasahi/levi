# Issue #340 教会利用者のメール招待とパスワード自己管理

## 目的

教会作成時の一時パスワード共有を廃止し、教会利用者本人へ24時間有効のパスワード設定メールを送信する。また、利用者がログイン画面から再設定し、ログイン後にも現在のパスワードを使って変更できるようにする。

## 実装方針

- 教会と資格情報は `PENDING` で作成し、Better Auth のパスワード再設定リンクを招待メールとして送る。
- メール送信に失敗した場合は新規作成した教会・利用者を削除し、利用不能な途中状態を残さない。
- 招待リンクでパスワード設定が成功した時だけ利用者を `ACTIVE` にする。
- パスワード設定・再設定リンクの有効期限は24時間とする。
- ログイン済み利用者は設定メニューから現在のパスワードを確認したうえで変更できる。
- 存在するメールアドレスを推測できないよう、再設定依頼の応答は常に同じ文言にする。
