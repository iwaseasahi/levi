# Archived execution plans

Files in this directory preserve implementation history only. They are not
current operating instructions.

The provider-API orchestration experiment for Issue #2 was retired on
2026-08-21. The subsequent dual-client policy was superseded by Issue #62; Levi
now uses only local subscription-authenticated Codex, as defined by
[`../../agent-protocol.md`](../../agent-protocol.md). Commands, workflow names,
credentials, and resume instructions in archived plans must not be executed.
