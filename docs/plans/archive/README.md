# Archived execution plans

Files in this directory preserve implementation history only. They are not
current operating instructions.

The provider-API orchestration experiment for Issue #2 was retired on
2026-08-21. Levi now uses local subscription-authenticated Codex and Claude Code
clients, as defined by [`../../agent-protocol.md`](../../agent-protocol.md).
Commands, workflow names, credentials, and resume instructions in archived plans
must not be executed.
